# Samples

EPUB files are not committed to this repo (one of them, "L'Autre Moi" by Franck Thilliez, is
under copyright; the other, a public-domain Project Gutenberg edition of *Les Misérables*
Tome I ("Fantine"), is excluded too just to keep the repo lean).

To run the prototype's default test book, download a *Les Misérables* Tome I EPUB (e.g. from
Project Gutenberg) and place it at:

```
samples/Les misérables Tome I Fantine.epub
```

or pass a different path via `--book`.
